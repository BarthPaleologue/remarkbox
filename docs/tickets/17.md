# T17 — Operation Undigg II: reddit/digg pivot on undigg.com

**Status:** open
**Priority:** high
**Source:** fox directive 2026-07-27

## Summary

Move remarkbox from hobby to profits by launching undigg.com — a reddit/digg
style community platform — as our flagship deployment of this codebase.
Communities are wildcard subdomains (`{name}.undigg.com`), which our existing
namespace-per-hostname resolution supports with zero new routing code.
Generative machine learning produces a unique, accessible theme per community
(`Namespace.stylesheet` storage already exists).

Full audit + phased plan: [docs/roadmap-undigg.md](../roadmap-undigg.md)

## Phases (see roadmap for detail)

- P0 — stand up undigg.com: wildcard DNS/TLS, community creation flow, front page, body-size cap (G9)
- P1 — voting + karma + hot/top/new ranking (wake dormant `rb_vote` table)
- P2 — link submissions with `Uri` dedup + OG cards
- P3 — generative machine learning themes per community + seed catalog
- P4 — discovery: FTS search, trending, feeds
- P5 — monetization: wire Stripe webhook → entitlements (G6), pay-what-you-can, powered-up communities
- P6 — scale: Postgres path, caching, caretakers-before-surge moderation

## Done when

undigg.com serves an aggregated front page over user-created communities with
voting, ranking, link submissions, generated themes, and at least one live
revenue stream wired end-to-end.
