## Namespace privacy needs no configuration

Namespaces are public by default and privacy enforces itself — there is no ini
setting. `namespace.enforce_private_lists` existed only while our migration
chain was stalled and production rows still read `public = False`; that is
fixed (T22) and every namespace is backfilled, so the switch was removed
rather than left as sprawl.
