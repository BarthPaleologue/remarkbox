## Namespace privacy is on by default

Namespaces are public by default, so enforcement needs no configuration.
Migrations run themselves: `foxhop-states/uwsgi/sites.sls` runs
`alembic upgrade head` on every release, `onchanges` the new tarball moving
into place, which is how `554e2329ebf0` (backfill) and `df0217588814` (token
table) reached production with `5acecdd`.

An earlier note here claimed no migration step existed. That was wrong — it
searched `remarkbox-states`, which is stale jenkins-era, plus our CI config,
and never checked `foxhop-states`, which is what actually deploys us.

`namespace.enforce_private_lists = false` remains as a kill switch, for a
database predating our backfill or if list privacy ever misbehaves.
