## Remaining

- **S3** — needs fox's call: bearer tokens for API writes (correct, breaks our
  cookie-authenticated Python/C clients) vs. the interim pair of requiring
  `Content-Type: application/json` plus an `Origin` check (small, keeps clients
  working). Recommendation: interim now, bearer tokens with undigg.com's API work.
- **S4** — product decision: enforce `Namespace.public` or drop the column.
- **Export cost buckets** — give `pdf`/`epub`/`docx` their own lower rate limit
  before public signups.
